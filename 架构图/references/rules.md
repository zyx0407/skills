# 架构图 / 结构图 · 规矩全文

> 这份文件是 skill 的详细依据；SKILL.md 是摘要版。两套配色：纸色（默认）与深灰（备选）。

## 一、版式骨架

```
画布 1400 × 700~920，外边距 40
┌──────────────────────────────────────────────────────┐
│ 标题：主题 · 副题 · 日期（右下角可放版本/状态）          │
│                                                      │
│ 左列（40~380）   中列（460~980）    右列（1060~1360）  │
│ 外部/用户        本体/核心          数据/上线/运维      │
│  三块             一块总名+六小块     三块              │
│                                                      │
│ 底条（y≈490~600）：边界 · 验收 · 现状（三块横排）        │
│ 图例（底部 20px）：实线 / 虚线 / 灰字含义                │
└──────────────────────────────────────────────────────┘
```

- 列头 `.g`：等宽 10.5px、字距 0.14em、灰字，写该列语义。
- 框 `.box`：圆角 12、内边距 11/14、1px 边；虚线框表示"外部/计划/只读可选"。
- 框标题 `.t` 14px/500；说明 `.s` 10px 等宽、行高 1.7、灰字。
- 线：1px；实线直连；虚线异步/定时/可选。箭头 7px。
- 线上标签 `.lbl`：9.5px 等宽灰字，放线上方或拐角外侧。

## 二、12 条规矩（逐条）

1. **一张图一个 scope**：用户视角 / 部署机器 / 数据流，挑一种；混了就拆两张。
2. **标题三件套**：`主题 · 副题 · 日期`；有版本就带版本（例：`v1.2`）。
3. **每框两行**：第一行"它是什么"，第二行"它干什么 + 技术选型"。
4. **边框语义**：实线＝已落地；虚线＝外部/计划/只读可选。
5. **箭头必须有标签**：写"谁把什么给谁"（读数据 / 推送 / 点进 / 验收）。
6. **线型语义**：实线＝同步直连；虚线＝异步、定时、可选、只读。
7. **颜色只做语义**：唯一强调色（琥珀 `#b08a3e`）只标"当前/待办/风险"，其余全灰阶；禁渐变、禁投影。
8. **版式固定**：左外部 → 中本体 → 右数据/上线 → 底条边界/验收/现状；不自由摆放。
9. **一屏读完**：1400 宽、700–920 高、字号 10–15px；超了拆图。
10. **图下 3–5 条 key facts**：最重要数字（条数、到期日、版本、白名单）。
11. **标明时态**：已落地 vs 计划，虚线 + 图例 + 日期三处一致。
12. **生成方式**：手写 HTML+SVG；CSS 变量切主题；无头 Edge/Chrome 出 PNG；真源与出图同目录（`_shots\`）。

## 三、评审 10 问（出图前自检）

1. 有标题吗？标题含范围与日期吗？
2. 有图例吗？解释实线/虚线/灰字吗？
3. 每个框都有名字与职责吗？
4. 每个框的类型清楚吗（系统/模块/数据/外部）？
5. 每条箭头都有标签吗？方向与文字一致吗？
6. 线型含义一致吗（实线≠虚线混用）？
7. 颜色只用一个强调色吗？有无装饰性渐变/投影？
8. "已落地"与"计划/外部"一眼能分开吗？
9. 一屏能读完吗？有没有压字、线穿框？
10. 有日期/版本吗？改动后更新了吗？

## 五、文件与命名

```
<主题>\架构图\
  index.html        真源
  _shots\<名字>.png  出图（2x 用 -Scale 2）
```

- 一个主题一个目录；多张图时加后缀（`-数据流`、`-部署`）。
- 出图名与主题一致；改版后覆盖同名 PNG，不留 `_v2` 堆文件。
- 需要分享/交付时：PNG 给手机看，`index.html` 给能开浏览器的人自己点。

## 六、动态（默认不做；明确要求才允许"连线流动"）

- **默认静态**（可截图 / 打印 / 贴文档）；只有明确要求动态时才加。
- 加也只允许一种：在关键连线旁加一个沿路径流动的小圆点（SMIL `animateMotion` + `mpath`），表示"数据在跑"。
- 静态导出/打印用 `?still=1` 隐藏流动层；`prefers-reduced-motion` 自动静止。
- **不要**做悬停高亮、分步讲解、自动播放等交互——除非需求明确要求（它们会让图变"演示"，不是"地图"）。
