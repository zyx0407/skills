# 通知 · ntfy 自建推送

自己架一台 ntfy，手机/电脑都能收通知，**不走第三方推送服务**。

## 是什么

- 服务端：`ntfy` 2.x，只监听组网地址（不暴露公网），`auth-default-access: deny-all`；
- 每台设备一个订阅客户端，消息标题带来源前缀 `[电脑]`／`[服务器]`／`[手机]`；
- 电脑端还有个常驻脚本，转成 Windows 系统通知。

## 怎么用

```powershell
# 发一条
.\ntfy.ps1 -Send "备份完成"
# 常驻监听（转系统通知）
.\ntfy.ps1 -Listen
```

## 规则

- 前缀自动加，**电脑自己发的不回弹**；
- 重大事故双发（ntfy + 邮件）；
- 凭据只落本机 `secrets`，不进仓库。

## 边界

- 手机要能收到，得先连上组网；断网＝收不到（但服务器会记日志）。
- 只能主动查、不能"实时感知"——它不是长连接推送器。
