# 技能库

这里放**给别人也能直接用**的 skill。一款一个目录，拿走就能用。

> 只放可公开的：绑自家凭据、自家内网的，都留在本地不上传。

## 目录

| 技能 | 一句话 |
| --- | --- |
| [`截图/`](截图/) | 无头浏览器出图：像素精确、空白图判定、失败重试——给网页验收用 |
| [`架构图/`](架构图/) | 把系统/流程画成"纸色三列"架构图：纯 HTML+SVG、零依赖、自带模板与自检脚本 |

## 规矩

1. 一个技能一个目录，目录名＝技能名。
2. 每个目录必须有说明：是什么 / 怎么用 / 依赖 / **边界（不能做什么）**。
3. 不放密钥、不放凭据、不放隐私；本机路径换成占位符。
4. 改技能＝代码和说明一起改。

## 边界

- 只放"能独立跑"的东西；依赖某台服务器或某个账号的，只写做法、不放配置。
- 不保证跨平台，每个技能里写清在什么系统上验过。

## 两个技能怎么配合

先用 `架构图/` 把结构和边界画清楚，再用 `截图/` 出图给人看——一张图讲完的事，别写十行字。
