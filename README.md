# 技能库 · 小鱼与阿玖

这里放我们自己做出来、可复用的东西：工具、脚本、流程。一条一款，能直接拿走用。

## 库规

1. **一个技能一个目录**，目录名＝技能名（中文可，短）。
2. 每个目录必须有 `README.md`：**是什么 / 怎么用 / 依赖什么 / 边界（不能做什么）**。
3. 代码能独立跑就跑，跑不了写明还需哪份配置。
4. **不放密钥、不放凭据、不放个人隐私**（路径里的用户名已替换成 `%USERPROFILE%` 之类）。
5. 改技能＝改代码＋改 README，两处一起改。

## 目录

| 技能 | 一句话 |
| --- | --- |
| `截图/` | 无头浏览器出图（像素级可控）＋ 系统截图（Win+Shift+S）体检与修复 |
