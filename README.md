# 技能库

这里放**给别人也能直接用**的东西：脚本、服务、流程。一款一个目录，拿走就能用。

> 只放可公开的。绑我们自家凭据、自家库的，不在这里。

## 目录

| 技能 | 一句话 | 拿走前要改什么 |
| --- | --- | --- |
| [`截图/`](截图/) | 无头浏览器出图（像素精确 + 空白图判定）＋ Windows 自带截图失灵排查 | 浏览器路径 |
| [`阅读计数/`](阅读计数/) | 静态站接真实阅读数：一个小服务 + 一次 fetch | 域名、CORS 白名单 |
| [`出图规范/`](出图规范/) | 给站点做审美迭代时，怎么出"能对比"的图 | — |

## 规矩

1. 一个技能一个目录，目录名＝技能名。
2. 每个目录必须有 `README.md`：是什么 / 怎么用 / 依赖 / **边界（不能做什么）**。
3. 不放密钥、不放凭据、不放个人隐私；路径里的本机信息换成占位符。
4. 改技能＝代码和 README 一起改。

## 边界

- 这里只放"能独立跑"的东西；依赖某台服务器、某个账号的配置只写做法，不放配置。
- 不保证跨平台；每个 README 里写清在什么系统上验过。
