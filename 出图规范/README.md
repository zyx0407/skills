# 出图规范 · 给站点出对照图的规矩

做审美类改版时，「我觉得好看」没用，要给他**能直接对比的图**。这套规矩是踩出来的。

## 四条铁律

1. **改一处出一张图**，别攒到最后一起出——他判断的是这一处。
2. **同尺寸、同背景、同字号**，只改待对比的那一个变量；颜色/结构混着改就没法看。
3. **昼夜各出一张**（站点有 night 主题时），夜里常常看不出问题。
4. **图要能被机器判定**：空白图、全同色图当失败处理，别把坏图递上去。

## 常用参数

- 冻结动画：URL 加 `?still=1`、`?nofade=1`；
- 窄屏：`--w 390`（内部会用 iframe 外壳绕开 504px 最小视口）；
- 桌面基准：`--w 1440 --h 900`。

## 交付方式

- 看图的人看不到图时（客户/预览端故障），**直接开本地页面**给他看，比贴图可靠。
- 文件名带版本：`顶栏v10-日.png`、`顶栏v11-日.png`，**不要覆盖同名文件**（预览端会缓存失效）。

## 边界

- 只解决"看得见、可比对"；"好不好看"仍然是他拍板。
- 像素 diff 只能证明"变了"，不能证明"变好了"。
