# 记忆体检 · 自审查记忆库

记忆库分片有硬上限（单片 12KB、核心 10KB），格式有契约。这个技能＝**每次改完自查一遍**，别让库悄悄坏掉。

## 怎么用

```bash
node _tools/记忆体检/记忆体检.js      # 体检：超限、格式、日期、重复、贴顶告警
node _tools/记忆体检/indexer.js --rebuild   # 重建索引（sqlite FTS5）
node _tools/记忆体检/indexer.js --search "关键词"  # 查库
```

体检必须 **ERROR 0 · WARN 0** 才算干净；有 WARN 就先瘦身再写新东西。

## 规则

- **写之前先跑体检**：知道哪片快满了，才不会写完就超。
- 超了不许硬塞：先压措辞，再考虑拆片。
- 重复的事实只留一处，冲突当场办。

## 边界

- 它只查"结构"和"体积"，不判断内容对不对、该不该记。
- 日期格式错、路径写错它也不认得，只能靠写的人。
